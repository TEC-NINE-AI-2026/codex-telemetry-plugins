耗时与分位数

轮次耗时
从任务开始到完成、中止或当前时刻的墙钟时间。
TTFT
Time to First Token，从轮次开始到首个 Token。Codex 未提供明确字段时，使用首个非输入阶段并标记为“估算”。
P50 / P95
分别有 50% / 95% 样本不超过该值；只统计具备完整耗时的已完成轮次。
阶段分布
接收、推理、工具、中间回复、最终回复与其他开销按时间区间去重分配，避免重叠时重复计时。

Token 与占比

总 Token
优先使用 Codex 报告的总数；字段缺失时为输入 Token 加输出 Token。
输入 / 输出
输入包含发送给模型的上下文；输出包含模型生成内容，推理输出是输出的子集。
推理占比
推理输出 Token ÷ 输出 Token。
平均 Token
当前筛选条件下各轮次总 Token 的算术平均值。

缓存效率

缓存输入
输入 Token 中由缓存命中的子集。
未缓存输入
输入 Token − 缓存输入 Token，最小为 0。
缓存写入
Codex 明确报告的新写入缓存 Token，不从其他字段推算。
缓存命中率
缓存输入 Token ÷ 输入 Token。

上下文健康

上下文峰值
轮次内最大上下文输入 ÷ 模型上下文窗口。
预警 / 危险
峰值达到 70% 为预警，达到 85% 为危险；这是面板启发式阈值，并非 Codex 官方限额。
上下文压缩
日志中明确识别到的压缩阶段及其耗时。

并发与可靠性

当前 / 峰值并发
同时处于运行区间的任务数，以及筛选范围内的最大值。
重叠轮次比例
与至少另一个轮次发生时间重叠的轮次数 ÷ 有有效区间的轮次数。
完成率
已完成 ÷（已完成 + 已中止 + 不完整）；运行中不进入分母。

工具、智能体与额度

工具失败率
明确归一化为失败的调用 ÷ 明确成功或失败的调用；未知状态不进入分母。
累计工具时长
各工具阶段耗时之和，可能包含并行重叠。
智能体重叠率
匿名化智能体活动区间的并行重叠程度，不估算反事实节省时间。
订阅使用量
Codex 最近一次明确提供的额度窗口快照，不代表账单或费用估算。
