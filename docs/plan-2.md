- 插件及 Marketplace 包版本升级为 `1.2.0`，不提交、不推送 GitHub。

## Implementation Changes

### 数据采集与兼容

- 将 SQLite schema 升级至 v2，为轮次增加可扩展的安全维度元数据；工具和智能体信息继续存入阶段元数据。
- 仅采集白名单字段：模型、推理强度、速度、推理模式、运行方式、自动化类型、工具类别/名称、标准化状态及匿名化智能体关系。
- 命令、工具参数、工具输出、错误正文、原始推理和未知事件内容仍不得写入数据库；智能体 ID 使用稳定哈希。
- 升级时保留用户的历史清理截止时间，自动重新扫描已有 JSONL，为历史记录回填新指标；无法回填的字段显示“Codex 未提供”。
- 新增安全分类：
    - 工具：Shell、MCP、插件/动态工具、文件变更、图片查看、Computer Use、子智能体及未知类别。
    - 状态：成功、失败、中止、取消、未知；未知状态不计入失败率。
    - 工作模式：本地、worktree、云端、handoff、后台、自动化、未知；不根据标题或目录猜测。

### 指标与本地 API

- 新增 `GET /api/analytics`，沿用现有令牌认证，支持时间、项目、模型、推理强度、状态和工作模式筛选。
- 响应包含 `coverage`、`overview`、`efficiency`、`cache`、`tools`、`agents`、`context`、`reliability`、`concurrency` 和 `workModes`；字段无来源时返回 `null`/空集合并附覆盖状态。
- 保持现有 `/api/summary`、`/api/tasks`、任务轮次接口兼容，仅追加筛选维度和安全元数据。
- 固定指标口径：
    - 完成率 = 已完成 ÷（已完成 + 已中止 + 不完整），运行中不参与。
    - 缓存命中率 = 缓存输入 Token ÷ 输入 Token。
    - 推理占比 = 推理输出 Token ÷ 输出 Token。
    - 工具失败率仅统计已识别成功或失败状态。
    - 上下文预警为峰值达到 70%，危险为达到 85%，并在界面标注为面板启发式阈值。
    - 并发峰值按轮次时间区间重叠计算；不估算“节省时间”，只展示重叠率、父子累计耗时和实际墙钟时间。
    - P50/P95 仅使用有完整时间数据的已完成轮次。

### 页面与交互

- 顶部保留实时状态、额度快照、全局筛选、重新导入和清空历史。
- 设置五个标签页：
    - 概览：完成率、P50/P95、TTFT、Token、缓存命中、上下文风险、当前与峰值并发、工作模式分布。
    - 效率：模型 × 推理强度矩阵、耗时/Token/完成率对比、缓存读取与写入趋势。
    - 工具与智能体：工具调用量、累计耗时、P95、失败率、类别趋势，以及可用时的父子智能体时间线和并行重叠率。
    - 上下文健康：上下文峰值分布、增长趋势、压缩次数/耗时、预警与危险任务。
    - 任务：保留现有任务和轮次详情，增加工作模式、工具摘要、可靠性状态和并发时间线。
- 自动化、handoff、云端及多智能体字段没有日志支持时，显示独立空状态，不隐藏整个标签页，也不生成估算值。
- 更新标题、Manifest 描述、Skill 触发描述、README、隐私说明、发布清单和 Changelog，使名称统一为“Codex 效率与健康度分析面板”。
