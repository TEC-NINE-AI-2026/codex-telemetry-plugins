| 建议增加的面板 | 可展示的数据 | 可行性 |
|---|---|---|
| 模型效率对比 | Sol/Terra/Luna 各自的平均耗时、TTFT、Token、完成率；按 `none`～`max` 推理强度比较 | 高 |
| 缓存效率 | 缓存命中率、缓存读取/写入 Token、未缓存输入、各项目节省比例 | 很高，当前已采集 |
| 工具与插件健康度 | Shell、MCP、插件、浏览器、文件修改等调用次数、耗时占比、失败率、重试次数 | 高，需要补充安全的工具名称字段 |
| 多智能体分析 | 子智能体数量、并行度、委派深度、各智能体耗时与 Token、关键路径、失败智能体 | 中高 |
| 上下文健康度 | 上下文增长速度、峰值、压缩次数和压缩耗时、接近窗口上限的任务 | 很高 |
| 任务可靠性 | 完成率、中止率、不完整率、错误率、重试率、长时间无响应任务 | 高 |
| 并发时间线 | 同时运行的任务数、任务重叠区间、排队时间、并行执行甘特图 | 高 |
| 自动化与后台任务 | 手动/定时任务比例、成功率、运行时长、最近失败、下次运行时间 | 中，需要读取自动化元数据 |
| 工作模式 | 本地、worktree、云端、handoff、后台运行的任务数量与耗时对比 | 中，取决于日志字段 |
| 代码产出 | 修改文件数、增删行、测试执行与通过率、提交/PR/代码审查数量 | 中，需要接 Git/GitHub |
| 额度与 Credits | 主/次额度窗口、余额、消耗趋势、重置倒计时、额度告警 | 部分可做；精确消费需后台数据 |
| 质量评估 | 用户评分、验收通过率、测试通过率、返工次数、每次成功任务的 Token 成本 | 需要额外数据源 |
